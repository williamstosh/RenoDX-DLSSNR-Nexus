# 构建与验证规程

核验日期：2026-10-23；范围：继承的验证规程及 Nexus 可用工具。本文规定验收要求，不代表旧项目测试工具已安装或集成。当前就绪情况以 [NOW](NOW.md) 为准；原规程、测试和证据由不纳入版本控制的本地索引定位。

## 按改动选择检查

| 改动 | 必需证据 |
| --- | --- |
| 规则或文档 | 审查内容、直接路径／链接及公开适宜性；`git diff --check` |
| 版本／构建集成 | `tools/check-version.ps1`、受影响目标／资源检查、源码／PE／包／标签版本一致性 |
| 宿主共享 API | 针对真实接口的对象身份／引用生命周期、事务／并发、失败恢复测试，以及受影响构建 |
| NR/FG 行为 | 针对性复现及受影响的 GPU／生命周期／配置测试；适用的真实游戏／视觉检查 |

证据仅适用于明确标识的源码、宿主、依赖／运行时、输入和测量范围。复用未受影响的有效结果，变更后重验受影响部分；跳过、关闭、暂停或不可用均不算通过。不重启已被替代的探测序列、已关闭诊断或无关游戏矩阵。

## 构建并固定候选

1. 核对插件、兼容宿主、依赖、着色器工具和运行时身份。仅有源码导入或任意上游检出不构成兼容宿主；完整构建前须解决 NOW 所列阻塞，缺失 API 的实现必须可追溯。
2. 使用隔离、可写的宿主／构建目录，确保 `src/addons/dlss5` 插件与本检出一致。Detours 输出和生成文件不得污染共享依赖检出；修改代码前读取适用的宿主规则和 C++ 指南。
3. 复用现有封装脚本和目标，例如在 PowerShell 7 中执行：

   ```powershell
   ./tools/check-version.ps1
   ./tools/build.ps1 -RenodxRoot <compatible-host> -ToolRoot <shader-tools>
   ```

4. 本地验证记录须包含源码提交／未提交状态、宿主／依赖／工具身份、相关配置和着色器输入、实际退出码、产物哈希及验证范围。构建日志、私有安装路径和专有输入不得进入公开上下文。

资源探针或着色器成功不能证明完整 Nexus 二进制构建通过。保留加载文件名 `renodx-dlss5.addon64` 及现有运行时／配置身份。

## 游戏自动化与数据保护

旧工具仅有 Steam Witcher 3 DX12 会话流程的验证证据，不是通用游戏驱动。脚本、目标、保护工具和验证记录仍在原工作区，尚未导入 Nexus。复用前从本地索引核对来源和目标，先执行预检；缺少命令应记为验证缺口，不另装替代工具或视为通过。目录切换后须将可写输出、保护及恢复记录指向预期的隔离工作区，封装脚本不得静默写入旧工作区。

仅在已有授权场景内执行：

- 核对实际可执行文件、PID、进程创建时间、桌面／焦点状态、候选和目标存档。不接管已有会话，不向未知菜单输入。加载请求不等于场景确认；只用已验证的游戏进入步骤，无法确定自动选择的存档时停止。
- 输入前备份并保护原存档／配置，保护持续到游戏退出及错误恢复完成；核对最终哈希和意外新增存档后才解除。不得用过期备份覆盖已变化的数据、修改无关设置或绕过平台保护。
- 确认实际加载模块路径及启动／安装顺序；磁盘哈希不证明实际加载，也不等于内存哈希。按具体验收记录实际 API、FG 后端／倍率、NR 处理域、引导数据和 SDR/HDR 条件。
- 场景确认、采集、冒烟测试和菜单退出均复用已验证操作。遵守暂停／人工矩阵要求；缺少可靠自动化时使用人工协助。保留要求的叠加层和质量条件，任意等待时长不能证明场景有效。
- 遵守场景的安装授权，恢复临时测试改动；区分有备份的候选保留与完整安装回滚。保留候选不代表验收通过。

| 退出或故障 | 处理要求 |
| --- | --- |
| 已确认菜单退出 | 等待本次会话所属进程退出，检查退出／崩溃证据和保护结果 |
| 已识别的临时启动／加载／场景失败 | 仅在进程已退出、保护完好且无新增崩溃报告时重试，最多两次；保留每次尝试记录 |
| UI／身份不确定、保护／诊断失败，或存在新旧崩溃报告程序 | 停止自动重试，保留证据并诊断或请求介入 |
| 本次会话所属工作进程／游戏无法安全退出，包括权限拒绝 | 保持保护，记录所需人工操作，确认退出后才继续 |

## 证据与回归边界

冒烟测试／输入响应、NR 模型调用、GPU 提交、画面呈现 NR 效果、视觉质量和性能必须分别下结论。桌面截图不是原始 HDR 像素证据；黑屏／静帧检测仅为启发式，CPU 采样不测量 GPU 性能。WARP／模拟消费方和 SDK 初始化成功均不能证明真实 NR/FG 输出合格。

仅对受影响部分执行既有回归：配置迁移、同帧去重、资源生命周期／队列依赖、重置／部分失败、native/translated/FG-Off 路由及实际模式切换。详细步骤和现有测试在集成前仍由本地索引定位。标签、打包和发布遵循[版本规程](../VERSIONING.md)；构建成功不能替代缺失的运行／视觉证据。
