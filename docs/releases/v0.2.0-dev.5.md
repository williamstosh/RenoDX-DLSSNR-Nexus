# NR Nexus v0.2.0-dev.5 — Packaging Correction / 包装修正

<!-- Previous: v0.2.0-dev.4 -->

## 简体中文

### 版本亮点

本预发布修正 v0.2.0-dev.4 Windows 包的文档图片清单，使包内 README 与用户指南包含新的保存任务配图。插件代码、逐层阶段行为、配置及已记录的实机证据与 v0.2.0-dev.4 相同。

### 验证情况

打包测试核对包内 README／用户指南引用的每张本地图片均存在且与源文件字节一致；v0.2.0-dev.5 的 Release／Debug 与 PE 元数据另行核对。包仍为 30 项白名单，只含插件、文档、许可及校验文件。

### 已知限制

v0.2.0-dev.4 包缺少两张文档配图；请使用 v0.2.0-dev.5 获取完整包。逐层阶段的实机证据仍只覆盖一款游戏、一个固定存档、两层、短时静止及一次短移动，且 RR／FG 关闭。跨阶段 Present、DX11/Vulkan 及 FG 接管 NR 输入的路径仍停用。这是开发预发布，不是正式版。

### 安装说明

下载 v0.2.0-dev.5 Windows x64 ZIP 并核对 `.zip.sha256`。关闭游戏、备份现有插件与游戏设置后，仅替换 `renodx-dlss5.addon64`，保留包内文档与许可声明。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；A/B 模型要求识别到 310.9.16.0。

## English

### Highlights

This pre-release corrects the v0.2.0-dev.4 Windows package so the packaged README and User Guide include the new preset save-task images. Plugin code, per-pass stage behavior, configuration and the recorded game evidence are unchanged from v0.2.0-dev.4.

### Validation

The package test verifies that every local image referenced by the packaged README and User Guide is present and byte-identical to the source. Release and Debug builds and PE metadata for v0.2.0-dev.5 are checked separately. The package remains a 30-entry whitelist with the plugin, documentation, licenses and checksum only.

### Known Limitations

The v0.2.0-dev.4 package omitted two documentation images; use v0.2.0-dev.5 for a complete package. The per-pass stage game evidence remains limited to one game, one fixed save, two stages, short still scenes and one short movement with RR/FG disabled. Cross-stage Present, DX11/Vulkan and FG-owned NR input paths remain disabled. This is a development pre-release, not a stable release.

### Installation

Download the v0.2.0-dev.5 Windows x64 ZIP and verify its `.zip.sha256`. Close the game, back up the existing add-on and game settings, and replace only `renodx-dlss5.addon64`; keep the included documentation and license notices. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` remain separate requirements; A/B models require a recognized 310.9.16.0 runtime.
