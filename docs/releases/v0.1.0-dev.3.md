# NR Nexus v0.1.0-dev.3 — DLSS NR 310.9.16 Dual Models / 双模型支持

<!-- Previous: v0.1.0-dev.2 -->

## Highlights

DLSS NR **310.9.16.0** brings two selectable models: **A (Legacy)** and **B (Small FP8)**. NR Nexus now lets you choose a model independently for up to four NR passes.

支持 DLSS NR **310.9.16.0** 的 **A（Legacy）**与 **B（Small FP8）**双模型，最多四个 NR Pass 可独立选择模型。

## Features

- Main **Auto** selects B on the recognized 310.9.16.0 runtime. Passes 2–4 can inherit the main model or explicitly select A/B, independently of appearance sharing. Existing explicit selections are preserved.
- Changing a model rebuilds the processing chain and resets temporal history. Existing GPU retirement protects old handles during the transition.

- 精确识别 310.9.16.0 时，主模型“自动”选择 B；Pass 2–4 可继承主模型或明确选择 A/B，与外观共享独立，保留已有显式设置。
- 切换模型会重建处理链并重置时序历史，旧句柄仍由既有 GPU 退休机制保护。

## Compatibility

Other or unidentified runtimes disable B in the menu and execute saved B requests as A without rewriting the saved choice; their Auto setting keeps the runtime default. Legacy preset 3 is hidden from the menu and resolves to A on 310.9.16; existing preset-3 settings appear as Custom.

旧版或未识别 Runtime 在菜单中禁用 B，已保存的 B 请求执行时回退 A，不改写原设置；其“自动”仍使用 Runtime 默认值。旧 Preset 3 不再显示于模型菜单，在 310.9.16 上回退 A；已有值显示为“自定义”。

## Validation

- Real RTX 5090 D inference with driver 617.14 / runtime 310.9.16.0: 13 groups and 53 evaluations covered A/B, AB/BA/BB, repeatability, resizing and overlapping handle retirement, with GPU completion and finite, non-identity output readback.
- The Witcher 3 D3D12, 4K HDR, Present + XeFG 4×: focused candidate sessions exercised A/B, mixed chains, runtime model switching, legacy-runtime fallback, normal exit and file restoration. Game evidence uses creation requests plus the verified runtime mapping, not a private in-game network query.
- Release/Debug builds, configuration/language checks and published-package verification passed. Game sessions used the preceding frozen development candidate; later menu cleanup and the dev.3 version rebuild were build/test verified, not rerun as a new full game matrix. These results do not establish HDR visual quality or a fixed performance gain.

- RTX 5090 D／驱动 617.14／Runtime 310.9.16.0 的真实 GPU 测试共 13 组、53 次推理，覆盖单模型、AB/BA/BB、重复性、尺寸重建及交叠退休，核对 GPU 完成与有限、非恒等输出。
- 《巫师 3》D3D12／4K HDR／Present＋XeFG 4× 的定向候选测试覆盖 A/B、混合链、运行中切换、旧 Runtime 回退、正常退出及文件恢复；游戏内按创建请求与已验证 Runtime 映射判断模型，不宣称通过私有接口确认实际网络。
- Release／Debug 构建、配置／语言检查及公开安装包核验通过。实机证据绑定此前冻结开发候选，后续菜单整理和 dev.3 升版重编经构建／测试核验，未重跑完整游戏矩阵；不据此宣称 HDR 画质或固定性能提升。

## Fixes

Release publication now handles empty, single and multiple Release responses and resumes matching drafts correctly. A separately reviewed publisher can recover an existing tag using its original validated package. The bilingual README was reorganized around player requirements, installation and verification limits.

修复 Release 列表解析及匹配草稿恢复，支持独立审查的发布工具复用原已验证安装包补发已有 Tag；双语 README 按玩家前置条件、安装及验证边界重组。

## Known Limitations

HDR image-quality judgment, long-duration stability, the full live per-pass switching matrix and cross-game/D3D11/Vulkan validation remain incomplete. Old resources may remain resident until safe retirement. Isolated timing samples are not game-FPS guarantees. The previously documented XeFG highlight flicker remains unresolved.

HDR 人眼画质、长期稳定性、完整逐 Pass 实机动态组合及跨游戏／D3D11／Vulkan 验证尚未完成。旧资源可能持续驻留至安全退休；隔离计时样本不代表游戏 FPS 保证。此前记录的 XeFG 高亮瞬闪仍未解决。

## Installation

Download the Windows x64 **ZIP release asset** and verify its `.zip.sha256` sidecar; GitHub's source archives are not installers. With the game closed, back up and replace only `renodx-dlss5.addon64`, preserving settings and license files. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` are required separately; use **310.9.16.0** for dual models. ReShade, NVIDIA runtimes and models are not bundled. See the packaged README for full setup and compatibility requirements.

下载 Windows x64 **ZIP 发布附件**并核对 `.zip.sha256`，勿将源码压缩包当作安装包。关闭游戏、备份后仅替换 `renodx-dlss5.addon64`，保留配置与许可文件。另需支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；双模型须使用 **310.9.16.0**。本包不附带 ReShade、NVIDIA Runtime 或模型，完整安装与兼容要求见包内 README。
