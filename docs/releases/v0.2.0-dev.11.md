## 简体中文

### 版本亮点

顶部状态使用近期有效源帧判断当前运行情况；会话累计失败继续保留在诊断中。新增可与参数编辑同时使用的非模态运行监视器，并在配置控件和方案应用前检查实际能力边界。

### 新增功能与改进

- F11 常驻性能 HUD 支持精简／详细与可选 10／30／60 秒趋势：帧率、帧间隔、NR GPU 和逐 Pass GPU。切换视图和 Home 编辑状态自动适应内容，保留手动尺寸偏好；按本游戏恢复上次显示选择，标题显示实际快捷键。背景不透明度默认 80%，监视器和高级页共用快捷定位、自定义及重置。帧率优先使用当前运行时的 Present 回调节奏，回退时标明 ImGui 来源；GPU 趋势保留原始完成样本的峰值，缺测留空。
- 高级页按快捷键与截图、运行时监视器、界面与通知、游戏修正与兼容性、开发与维护分组。屏幕提示增加九宫格、偏移与预览，保留旧百分比位置；介入点名称沿用各语言主菜单术语。
- F9/F10 分别推荐用于官方／自定义方案循环，各自默认关闭、可改绑；保留 F5/F6。跳过空的或当前不可用的自定义槽，使用原有保存、事务、回退与撤销。
- 合并快速方案的撤销／管理入口；Pass 2–4 固定比例提供 100%／67%／58%／50% 与自定义滑块，保留原存储编码。
- 官方候选模板升级至 v2，保留个人 Override 和自定义槽。Lite 为 Render/B/67%；Balanced 为 Upscaled/A/67%；Max 为 Render/B/67%/电影感 → Upscaled/A/67%/默认，两层均启用角色遮罩、角色／皮肤 0.75。
- 仅在确认无既有配置且没有当前游戏旧 Slot 证据时，首次初始化并实际应用 Balanced。未知、损坏、读取失败、已解除关联及旧配置均不自动覆盖。

### 修复内容

- 历史累计跳帧不再无限拖延黄色退出；新配置等待足够有效新样本，暂停或样本过期不显示已恢复。
- GPU 样本绑定录制时配置身份。跨 Stage 仅在所有阶段组近期有效、配置／设备／来源／显示条件／队列一致时显示 ~ 参考合计，每组总耗时只计一次；其余查看独立 Pass 数据，缺测与未运行分别显示。参考合计是近期 NR 成本，不是同帧端到端延迟。
- 保留已实现的 DX11 Bridge／DX12 双 Pass 异尺寸与 Render→Upscaled；同组三／四 Pass 异尺寸、未确认 FG Off 的普通 Present 异尺寸和缺少必要证明的路径在普通操作入口阻止提交，旧数据不删除。

### 验证情况

本轮包含生产 ImGui、配置事务／模板迁移、能力矩阵和 WARP 定向自动化。WARP 使用模型替身，截图使用合成运行数据；二者均不代表真实游戏中的 NR 画面、焦点交互或画质验收。

### 已知限制

三套官方配方为开发候选，尚待人工实机画质对比。真实游戏中的热键冲突、Overlay 焦点和显示环境变化仍需验证。内部模型网络无法回读；原生 Pre-FG 双 Pass 异尺寸研究保持 BLOCKED／NO-GO，不因本轮 UI 改造放宽门槛。

### 安装说明

本次仅同步开发源码，不创建 Tag 或 Release，不提供此版本安装包。后续发布仍需兼容的 ReShade Add-on 环境和合法取得的 NVIDIA 运行时；模型 B 需要已识别的兼容运行时。

## English

### Highlights

The top status uses recent eligible source frames to describe current operation. Session failures remain in Diagnostics. A nonmodal runtime monitor supports editing settings while observing execution, and capability checks guard configuration controls and profile application.

### Features & Improvements

- The persistent F11 performance HUD offers Compact/Details and optional 10/30/60-second trends for FPS, frame interval, NR GPU and per-pass GPU. View and Home editing changes fit content while retaining manual size preferences. Each game restores the last display choice, and the title shows the actual shortcut. Background opacity defaults to 80%; the monitor and Advanced share placement, custom positioning and reset. FPS prefers the current runtime's Present callback cadence and labels the ImGui fallback. GPU trends preserve peaks from raw completed samples and leave missing data empty.
- Advanced groups hotkeys/screenshots, the monitor, interface/notifications, game fixes/compatibility, and development/maintenance. Notifications gain nine anchors, offsets and preview while retaining old percentage placement. Stage labels share each language's menu vocabulary.
- F9/F10 are the recommended official/custom profile cycle keys. Both are independently disabled by default and can be rebound. F5/F6 remain available. Custom cycling skips empty or unavailable slots and uses existing save, transaction, rollback and Undo behavior.
- Quick profiles share a compact Undo/Manage row. Passes 2–4 offer 100%/67%/58%/50% shortcuts and a custom scale slider, retaining existing storage values.
- Official candidate templates advance to v2 while preserving personal overrides and custom slots. Lite uses Render/B/67%; Balanced uses Upscaled/A/67%; Max uses Render/B/67%/Cinematic followed by Upscaled/A/67%/Default, with character masking and skin strength 0.75 on both passes.
- First use applies Balanced only with confirmed fresh configuration and no surviving profile evidence for this game. Unknown, corrupt, unreadable, detached or existing configurations are not automatically overwritten.

### Fixes

- Historical skips no longer indefinitely delay recovery from partial status. Changed configurations need fresh evidence; paused or stale samples cannot claim recovery.
- GPU samples carry their recorded configuration identity. Cross-stage ~ reference sums require recent valid samples for all stage groups with matching configuration, device, source, display conditions and queue, counting each group span once. Otherwise, read individual pass data; missing measurements and passes that did not run are distinct. The reference sum describes recent NR cost, not same-frame end-to-end latency.
- Preserve implemented DX11 Bridge/DX12 two-pass independent sizes and Render→Upscaled. Ordinary controls reject incompatible three/four-pass groups, ordinary Present independent sizes without confirmed FG Off, and paths lacking required proof. Stored legacy values remain intact.

### Validation

This round includes production ImGui, configuration transactions/template migration, capability matrices and targeted WARP automation. WARP uses substitute models and snapshots use synthetic runtime data. Neither establishes actual game rendering, focus behavior or visual quality.

### Known Limitations

All three official recipes remain development candidates pending manual game comparisons. Actual game hotkey conflicts, overlay focus and display changes still require validation. The runtime's internal network cannot be read back. Native Pre-FG two-pass independent-size research remains BLOCKED/NO-GO with its existing gates.

### Installation

This change only synchronizes development source. It creates no Tag, Release or installation package. Future packages still require a compatible ReShade Add-on environment and a legally obtained NVIDIA runtime; model B requires an identified compatible runtime.
