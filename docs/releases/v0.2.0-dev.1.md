# NR Nexus v0.2.0-dev.1 — Local Presets / 本地预设

<!-- Previous: v0.1.0 -->

## Highlights

Save, share and review NR settings through a **local preset library**, JSON files or clipboard text. This development milestone adds scoped imports, grouped difference previews and undo while retaining existing per-pass model and inheritance behavior.

新增**本地预设库**，支持 JSON 文件／剪贴板分享、分范围导入、分组差异预览及撤销，保留既有逐层模型与继承行为。本版为开发里程碑。

## Features

- Choose quality, quality plus multi-pass, or full-backup scope. Compatibility settings are excluded by default; full backups require separate confirmation and are not universally portable.
- Review changed, unchanged, invalid and unknown fields before applying. Batch application verifies the ReShade configuration cache before updating runtime settings and coalesces rebuild effects; it is not an atomic disk/GPU transaction.
- Save, rename, copy or delete local library entries; import/export files or clipboard JSON. Undo restores the previous values for imported settings. Library files can be shared between games, but compatibility and rendered appearance still depend on each game.
- Exporting from Built-in effect reads the saved My settings. The preset session name is not persisted across restarts. UI controls and guidance cover all 15 interface languages.

- 提供画质、画质＋叠层、完整备份三种范围；兼容项默认排除，完整备份单独确认且不保证跨游戏兼容。
- 应用前查看变化、未变化、无效及未知字段；缓存回读通过后批量提交运行时设置并合并重建，不宣称磁盘／GPU 原子事务。
- 本地库支持保存、重命名、复制、删除及文件／剪贴板交换；撤销恢复导入字段原值。跨游戏共享文件不等于画质或兼容性一致。
- 内置效果视图导出“我的设置”，会话预设名不跨重启保存；15 种语言同步。

## Validation

The feature commit passed GitHub CI and Release/Debug builds. Focused local coverage includes 386 codec/store checks, 2,644 configuration checks (1,939 preset checks), 74,840 real-ImGui layout checks and 75,965 menu checks, plus language/branding and lifecycle tests. Store tests cover cross-module access and reparse-point rejection; controlled separate-INI tests cover library sharing and reload. These are automated fixture results, not proof of real-game preset application or image quality.

功能提交通过 GitHub CI、Release／Debug 构建；定向覆盖 386 项存储、2,644 项配置（其中预设 1,939 项）、74,840 项真实 ImGui 布局及 75,965 项菜单检查，并有语言／品牌和生命周期测试。跨模块、重解析点拒绝、独立 INI 共享／重载均为受控夹具证据，不冒充实机应用或画质验收。

## Known Limitations

Real-game preset import/export, clipboard use, restart persistence and GPU behavior after application remain unverified. Witcher 3 candidate sessions confirmed loading, scene entry, NR activity and restoration, but OCR failed to identify the preset entry; those sessions do not validate preset interaction. Cross-game/API, long-duration and controlled visual/performance testing remain incomplete. Existing HDR/FG limitations from 0.1.0 still apply. No runtime, model or measured performance data is stored in presets.

实机预设导入导出、剪贴板、重启保存及应用后 GPU 行为尚未验收。巫师 3 候选场景确认加载、NR 活动及恢复，但 OCR 未识别预设入口，不能算预设交互通过。跨游戏／API、长时、受控画质／性能未完成；沿用 0.1.0 的 HDR／FG 限制。预设不包含 Runtime、模型或性能测量数据。

## Installation

For an available versioned build, download the Windows x64 ZIP and verify its `.zip.sha256`; source archives are not installers. Close the game, back up settings and replace only `renodx-dlss5.addon64`, preserving the included documentation/licenses. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` are separate requirements; A/B models require recognized 310.9.16.0. See the packaged User Guide for preset scopes and preview controls. A source commit alone does not publish a release asset.

版本化构建公开后，下载 Windows x64 ZIP 并核对 `.zip.sha256`，源码包不是安装包。关闭游戏、备份设置后仅替换插件，保留文档／许可。另需支持完整 Add-on／API 18 的 ReShade 与合法兼容 NVIDIA Runtime；A/B 要求识别到 310.9.16.0。预设范围与预览操作见用户指南；仅推送源码不会公开发布附件。
