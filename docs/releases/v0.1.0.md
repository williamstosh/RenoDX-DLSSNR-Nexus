# NR Nexus v0.1.0 — Independent Per-Pass Editing / 逐层独立编辑

<!-- Previous: v0.1.0-dev.3 -->

## Highlights

The first stable NR Nexus release brings a sequential chain of up to **four NR passes**, independent model/style/result editing, and **four interface themes**. Compared with dev.3, the redesigned menu makes inherited and custom settings easier to inspect and edit. Additional passes increase GPU cost; they do not guarantee better image quality.

首个正式版提供最多**四层 NR 顺序处理链**、独立模型／风格／结果编辑及**四套界面主题**。相比 dev.3，重新组织的菜单便于查看和编辑继承与自定义设置；增加层数会提高 GPU 开销，不保证画质更好。

## Features

- **Dual models:** recognized DLSS NR **310.9.16.0** supports A (Legacy) and B (Small FP8). Main Auto selects B; later passes inherit or select A/B independently. Other runtimes retain their automatic default; saved B requests fall back compatibly without rewriting the saved choice. Model changes rebuild the chain and reset temporal history.
- **Per-pass freedom:** model selection, model styling and result inheritance are separate. Passes 2–4 inherit Pass 1 results by default, or independently shape brightness, colour, tonal ranges, detail, halos and temporal stability. Re-enabling inheritance preserves custom values. Working resolution, upsampling and processing location remain shared.
- **A clearer menu:** Quality, Multi-Pass, Diagnostics and Advanced pages; a stable live summary; selectable chain nodes; choice-specific explanations; one-shot expand/collapse; and 15 interface languages. Model strength, result strength and structure are described separately.
- **Themes:** Cyber Neon, Nexus Dark, Fluent Light and Midnight OLED apply immediately. Theme preferences are saved per game, independently of picture settings. Existing configurations without a theme retain Nexus Dark; new installations default to Cyber Neon.
- **FG/HDR and diagnostics:** existing native DLSS FG/MFG and XeFG coordination, Present resource/restoration policies and HDR controls remain available. FG declarations, observed NR routes and known/unknown multipliers are distinguished. Local diagnostic ZIP export and optional report sharing retain preview, consent and privacy filtering.
- **Offline help:** the ZIP now contains the bilingual User Guide, README, 12 interface illustrations and required licenses, with working local document/image links.

- **双模型：** 精确识别 **310.9.16.0** 时支持 A／B，主模型自动选 B，后续层独立选择或继承。其他 Runtime 保留兼容默认，已保存 B 请求按兼容规则回退且不改写保存值。切换模型重建处理链并重置历史。
- **逐层编辑：** 模型选择、模型风格和结果继承分开；第 2–4 层默认继承第 1 层结果，也可独立调整亮度、色彩、明暗范围、细节、光晕与时序稳定。重新继承保留自定义值；工作分辨率、上采样和介入点仍全链共享。
- **菜单与主题：** 四页导航、稳定摘要、可点击处理链、候选项说明、一次性批量折叠及 15 种语言；提供四主题即时切换，按游戏保存且不影响画质。旧配置缺主题键保留 Nexus Dark，新装默认 Cyber Neon。
- **协同与帮助：** 保留 NR／FG、Present／HDR 策略，区分声明、实际路径观测及未知倍率；诊断报告保留预览、同意和脱敏。安装包新增双语指南、12 张界面图及离线链接。

## Fixes

Release publication uses reviewed versioned notes rather than PR lists alone, validates direct-commit references, and safely resumes matching drafts. Packaging verifies offline documentation and rejects missing guides, Debug/wrong-version binaries and asset overwrites. Theme migration preserves existing/future configuration on read; FG display no longer treats an old Present multiplier as the current native FG multiplier.

发布采用版本化说明并追溯直接提交，安全恢复匹配草稿；打包检查指南、版本、Debug 拒绝及禁止覆盖。主题迁移保持已有／未来配置的读取兼容，FG 显示不再把旧 Present 倍率当作当前原生 FG 倍率。

## Known Limitations

Compatibility depends on game/API, driver, runtime and captured resources. HDR visual quality, controlled A/B parameter comparisons, long sessions, complete FG/fallback/multiplier combinations and broad cross-game/D3D11/Vulkan game coverage are not established. The previously recorded XeFG highlight flicker remains unresolved. Actual network-name readback and reliable native FG multiplier readback are unavailable; unknown is not reported as disabled. Theme selection/restart persistence across all four themes is not fully game-tested, and themes are not shared across games. Extra passes consume GPU time and memory; no fixed FPS or image-quality gain is promised.

兼容性取决于游戏／API、驱动、Runtime 与资源。HDR 人眼画质、受控 A/B 参数对比、长期稳定性、完整 FG／回退／倍率组合及跨游戏／D3D11／Vulkan 实机覆盖未完成；既有 XeFG 高亮瞬闪仍未解决。当前无实际网络名回读和可靠原生 FG 倍率回读，未知不等于关闭。四主题实机切换／重启保存尚未完整覆盖，主题不跨游戏共享；额外层消耗 GPU 时间与显存，不承诺固定帧率或画质提升。

## Installation

1. Download the Windows x64 **ZIP asset** and its `.zip.sha256` file; verify SHA-256 before extracting. GitHub source archives are not installable builds.
2. Close the game and back up the add-on/settings. Install or replace only **renodx-dlss5.addon64** in the appropriate ReShade add-on location, removing duplicate active copies. Preserve unrelated settings and dependencies.
3. Supply **ReShade with full add-on support / API 18** and a legally obtained compatible NVIDIA **nvngx_dlssnr.dll** separately; use **310.9.16.0** for A/B. The package does not redistribute ReShade, NVIDIA runtimes, models or SDKs. Follow the packaged README and USER_GUIDE.md for GPU/runtime prerequisites and game-specific placement.
4. Start with one pass and conservative defaults. Confirm the observed path in Diagnostics and compare NR Off/On in the same scene before adding layers.

1. 下载 Windows x64 **ZIP 附件**及 `.zip.sha256`，校验后解压；源码压缩包不是安装包。
2. 关闭游戏并备份插件／设置，仅安装或替换 **renodx-dlss5.addon64**，清除重复生效副本，保留无关设置与依赖。
3. 另行准备支持完整 Add-on／API 18 的 ReShade 及合法兼容的 **nvngx_dlssnr.dll**，A/B 要求 **310.9.16.0**；本包不附带 ReShade、NVIDIA Runtime、模型或 SDK。按包内 README／USER_GUIDE.md 核对硬件和安装位置。
4. 从单层与保守默认开始，在诊断中确认观测路径，同场景比较 NR 开／关后再加层。
