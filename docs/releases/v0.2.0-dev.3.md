# NR Nexus v0.2.0-dev.3 — Assisted Input and Preset UX / 辅助输入与预设界面

<!-- Previous: v0.2.0-dev.2 -->

## Highlights

Add an optional native Windows Unicode editor for preset, custom Slot and report text fields when the game's inline IME input is garbled, and reorganize preset/profile management around a single searchable library home with on-demand save and import tasks. The editor keeps its own input-method context, returns text only on **Apply**, and leaves ReShade's original inline input handling unchanged. This source version is unreleased; no v0.2.0-dev.3 package is published.

当游戏内原位 IME 输入出现乱码时，为预设、自定义 Slot 与报告文字字段新增可选的 Windows 原生 Unicode 编辑窗；同时把预设／方案管理整理为单一可搜索的方案库主页，保存与导入按需展开。编辑窗使用独立输入法上下文，仅在点“应用”时回填文字，不改变 ReShade 原有原位输入处理。此源码版本尚未发布，没有公开的 v0.2.0-dev.3 安装包。

## Features

- Open the same editor from a localized keyboard-icon button beside editable fields or from **Assisted input...** in the field's context menu. The icon is drawn geometrically, so a font without the glyph still shows it.
- **Apply** returns text to the original field only when its text has not changed meanwhile; **Cancel** leaves it untouched. Single-line fields do not apply on Enter. Escape first cancels an active IME composition. IME-aware Ctrl+C/V and candidate-selection behavior are covered by native-window tests.
- Preset search, name, author, source game, description and file paths, custom Slot names, and report text use the same path. Saving or exporting remains a separate explicit action. Fourteen translation tables and the bilingual guide were updated.
- The manual game-acceptance tools detect redirected AppData and relaunch the complete protected entry through the ordinary desktop context, so user presets and saves land in the normal per-user location. This is tooling only and does not change preset storage or ReShade.
- The Quality page puts the NR switch before a compact profile strip. An empty custom profile can be created in place from current settings or an official profile; long names remain identifiable in narrow windows; profile actions expose undo and a centered restore-confirmation modal.
- Preset management opens a library home with Save profile and Import profile tasks, folded custom tools, on-demand metadata/export fields, file actions only after selection, shared import undo, X/Escape closing and session window geometry. Storage formats, field ranges and apply semantics are unchanged.

- 可从可编辑字段旁的本地化键盘图标按钮，或字段右键菜单的 **辅助输入…** 打开同一编辑窗；图标由几何绘制，缺字字体仍可见。
- **应用**只在原字段未变化时回填；**取消**不改原文。单行字段按 Enter 不会应用；Escape 优先取消正在进行的 IME 组合。IME 相关的 Ctrl+C/V 与候选选择行为已由原生窗口测试覆盖。
- 预设搜索、名称、作者、来源游戏、描述与文件路径、自定义 Slot 名称及报告文字共用这一入口；保存／导出仍需另行执行。十四份翻译与双语指南已同步。
- 人工游戏验收工具会识别 AppData 重定向，并通过普通桌面上下文重启完整保护入口，使玩家预设与存档落在普通用户目录。此项仅影响测试工具，不改变预设存储或 ReShade。
- 画质页把 NR 开关放在紧凑方案区之前。空自定义方案可就地捕获当前设置或复制官方方案；窄窗仍能识别长名称；方案操作提供撤销与居中的恢复确认框。
- 预设管理改为方案库主页，保存与导入作为任务按需展开；自定义工具默认折叠，元数据／导出字段按需显示，选中文件后才出现文件操作。保留共用导入撤销、X／Esc 关闭及同会话窗口几何；存储格式、字段范围和应用语义未变。

## Validation

The final source passed Release and Debug builds, PE metadata and the affected automated suites. Recorded coverage includes 334 native Unicode editor checks, 24,480 layout scenarios with 81,968 checks, 80,006 production menu checks, eight hidden native Apply/Cancel flows, 38 localized geometry checks, 15-language branding, 2,962 configuration checks (including 2,259 preset checks), preset/profile/dialog regressions and 108 game-tool checks (one permission skip). The user validated Chinese and mixed-text entry, Ctrl+C/V in both input states, Apply/Cancel focus, saved preset reload and normal game exit/restore in Witcher 3 DX12. The later keyboard-icon and preset-UI changes were verified by builds, tests and offscreen ImGui rendering, not installed in the game; they are not claimed as new in-game visual acceptance.

最终源码通过 Release／Debug、PE 元数据及受影响自动化检查。记录覆盖 334 项原生 Unicode 编辑窗检查、24,480 个布局场景／81,968 项检查、80,006 项生产菜单、8 条隐藏原生 Apply／Cancel 流程、38 组本地化几何、15 种语言品牌、2,962 项配置检查（含 2,259 项预设）、预设／Slot／弹窗回归及 108 项游戏工具检查（1 项权限跳过）。用户在巫师3 DX12 中实测中文与混合输入、中英文状态 Ctrl+C/V、应用／取消焦点、保存预设重载及正常退出／恢复。后续键盘图标与预设界面经过构建、测试及 ImGui 离屏渲染检查，但未安装到游戏，不作为新的游戏内视觉验收。

## Known Limitations

The inline ReShade IME path remains affected by the host and is not changed by this editor. Other games, ReShade versions, exclusive fullscreen, long sessions, other Raw Input modes and the new keyboard icon in game remain unverified. The preset UI changes were not installed in a game: actual overlay width/DPI, fullscreen or multi-monitor placement, file-dialog focus, Slot save/switch behavior and restart association remain unverified. The description field's multi-line editor exists, but multi-line and complete candidate interactions were not part of the single-line user acceptance. No v0.2.0-dev.3 package exists; the published v0.2.0-dev.2 pre-release does not contain these changes.

ReShade 原位 IME 路径仍受宿主影响，本编辑窗不修改该链路。其他游戏、ReShade 版本、独占全屏、长时运行、其他 Raw Input 模式及新键盘图标的游戏内表现尚未验收。预设界面未安装到游戏：实际 Overlay 宽窄／DPI、全屏或多屏位置、文件选择焦点、方案保存／切换及重启关联仍未验收。描述字段支持多行编辑，但多行与完整候选交互不属于本轮单行实机验收。当前没有 v0.2.0-dev.3 安装包；已发布的 v0.2.0-dev.2 预发布不包含这些改动。

## Installation

This version has no published package. For a packaged build, use the latest published pre-release (v0.2.0-dev.2) and note that it does not include assisted input. To test this source, build it locally with the pinned host; do not install a source archive as an add-on. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` remain separate requirements.

本版本没有公开安装包。需要打包版本时请使用最新公开预发布 v0.2.0-dev.2，并注意它不包含辅助输入。测试此源码须使用固定宿主本地构建；源码压缩包不能作为插件安装。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`。
