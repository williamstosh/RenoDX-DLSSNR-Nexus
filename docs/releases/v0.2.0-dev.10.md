## 简体中文

### 版本亮点

开发源码的详细诊断现在可展示与实际 Stage、Pass、模型请求及工作尺寸绑定的 GPU 计时。只有录制关闭、对应工作精确提交一次且 GPU 完成得到证明时，样本才显示为有效。

### 新增功能与改进

- 最多四层分别显示 Encode、NGX GPU 区间、Resolve、已执行 Look、Pass span、实际 StageGroup GPU span 及非模型 GPU 时间，并标出工作／网络输出尺寸与模型创建请求。
- 按 Stage 分组，最多平均四个满足同队列、Pass、模型、尺寸及 Look 契约的样本；约 0.5 秒刷新，2 秒无新有效读数后过期。未执行、丢弃、重放及不完整样本显示明确状态，不伪装为零耗时。
- 多 Stage 的 GPU span 不再相加为整帧延迟；旧帧率成本估计仅在单一近期有效 Stage 下显示。
- 原生 Pre-FG Present 双 Pass 异尺寸研究状态更新为 BLOCKED／NO-GO。其开关仍默认关闭；这不改变独立的 Render → Upscaled 与原生 DLSS FG／XeFG 路径。

### 验证情况

- 定向 `gpu-pass-diagnostics` WARP 测试通过，覆盖生产双层尺寸与 Stage 归属、录制／提交／重放证明、样本生命周期、时间戳及 UI 读数。模型使用 GPU 拷贝替身，不代表真实 NVIDIA 网络。
- 相同功能源码的 Release／Debug 构建与 dev.9 PE 版本核对已通过；版本递增后 `tools/check-version.ps1` 与 `git diff --check` 通过。
- 双语诊断 Quick 预览的 252 项检查与品牌检查通过。未进行游戏、安装、实际加载、实机画质或硬件性能开销验收。

### 已知限制

计时反映带既有边界 barrier 的 GPU 区间，不测量模型内部网络、纯内核时间、CPU 等待或跨 StageGroup 的整帧延迟。实际 NVIDIA 网络行为、游戏适用性及真实硬件开销仍未验证。原生 Pre-FG Present 双 Pass 异尺寸仍 BLOCKED／NO-GO。

### 安装说明

此开发同步没有发布 v0.2.0-dev.10 安装包。若该版本后续获准预发布，请从本项目 Releases 下载对应 Windows x64 ZIP 并核对 `.zip.sha256`；仍需支持完整 Add-on／API 18 的 ReShade，以及合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`。A/B 模型要求识别到 310.9.16.0 运行时。

## English

### Highlights

Detailed diagnostics in the development source now show GPU timings bound to the actual Stage, Pass, model request and working dimensions. A sample is valid only after its recording is closed, its work is submitted exactly once, and GPU completion is proven.

### Features & Improvements

- Up to four passes report Encode, NGX GPU span, Resolve, executed Look, Pass span, measured StageGroup GPU span and non-model GPU time, with working/network-output dimensions and the model creation request.
- Samples are grouped by Stage and averaged across at most four entries with matching queue, Pass, model, dimensions and Look contract. They refresh about every 0.5 seconds and expire after 2 seconds without a new valid reading. Unexecuted, discarded, replayed and incomplete samples have explicit states rather than invented zero timings.
- GPU spans from multiple Stages are no longer combined into whole-frame latency. The legacy frame-rate cost estimate appears only for one recent valid Stage.
- Native Pre-FG Present pairs with different pass sizes are documented as BLOCKED/NO-GO. The experimental switch remains off by default; this does not change the separate Render → Upscaled path alongside native DLSS FG/XeFG.

### Validation

- The focused `gpu-pass-diagnostics` WARP suite passed for production two-pass dimensions and Stage attribution, recording/submission/replay proofs, sample lifecycle, timestamp handling and UI readouts. The model uses a GPU-copy substitute and does not represent the NVIDIA network.
- Release/Debug builds and dev.9 PE version checks passed for the same feature source; after the version increment, `tools/check-version.ps1` and `git diff --check` passed.
- The bilingual diagnostics Quick preview passed 252 checks, and the branding check passed. No game, installation, actual-load, image-quality or hardware-overhead acceptance was performed.

### Known Limitations

Timings represent GPU spans with the existing boundary barriers. They do not measure the model's internal network, isolated kernel time, CPU waits or whole-frame latency across StageGroups. Actual NVIDIA network behavior, game suitability and real hardware overhead remain unverified. Native Pre-FG Present pairs with different sizes remain BLOCKED/NO-GO.

### Installation

This development sync does not publish a v0.2.0-dev.10 package. If a pre-release is authorized later, download the matching Windows x64 ZIP from this project's Releases and verify its `.zip.sha256`. ReShade with full add-on support/API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` are still required; A/B models require a recognized 310.9.16.0 runtime.
