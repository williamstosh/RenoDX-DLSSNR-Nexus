## 简体中文

### 版本亮点

新增区域遮罩：分别控制 NR 的应用量、局部色调与结构，也可以让远处的 NR 平滑减弱，保留原画面。画质页和叠层页使用同一组控件，最多四层可继承第 1 层或独立调整。

### 新增功能与改进

- 提供全画面自定义、全画面标准遮罩、按深度衰减三种方式。深度衰减调节红色强度通道，绿色色调与蓝色结构仍可分别设置。
- 在“画质 → 外观与结果 → 模型风格”中启用区域遮罩；叠层页每一层也都有入口，位于模型外观之后、结果调整之前。启用开关作用于所有层。
- 深度控件采用更易调整远处范围的固定刻度，提供“远景起步”“仅远平面”、六位精确输入及四行单项恢复按钮。默认深度为 `0.999900 / 0.999950`。
- 混合模式使用“替换／平均／取较小值／取较大值”名称，补充与角色遮罩、RGB 通道和深度端点的关系说明，并同步多语言。

### 修复内容

- 修复旧诊断配置与已有处理历史导致 Render、Present 或切回 Upscaled 后 NR 无法继续运行的问题。
- 改善关闭区域遮罩后的工作集复用，补齐相关资源生命周期与失败恢复处理。
- 修复旧方案或导入设置绕过深度默认迁移的问题。精确旧默认 `0.7 / 0.9` 会迁移，其他合法自定义范围保留。
- 固定实际／预计工作分辨率的显示位置，避免切换介入点时菜单瞬间跳动。
- 补齐 Pass 1 的区域遮罩入口，统一后续层的设置位置，并修复微小深度变化未显示恢复按钮的问题。

### 验证情况

发布前最新开发候选已由用户确认完成实机核验。配置与方案、菜单与布局、多语言、Release／Debug 构建和 207 场景 UI 快照检查通过。区域遮罩此前已完成定向 WARP、硬件 GPU 与原生 NGX 验证，覆盖范围按各处理路径分别记录。

v0.3.0 发行构建由 Tag 工作流执行 Windows 构建、自动测试、PE 版本与打包检查；最终附件核对源码身份、包内容和 SHA-256。实机确认覆盖本次用户测试的场景，不扩展为所有游戏与组合的兼容性认证。

### 已知限制

- 区域遮罩需要兼容的 NR Runtime 和处理路径。深度是归一化游戏深度，不是米制距离；“仅远平面”按深度选择区域，不识别语义天空。不同游戏可能需要调整范围。
- 暗部与运动区域规则尚未提供。三四层任意异尺寸、Vulkan 混合阶段／独立缩放，以及原生 Pre-FG 的部分特殊组合仍未开放，详见玩家指南。
- 此前收到过一次启用遮罩后挂起的报告；定向复验未复现，原因尚未确定。如再次遇到，请保留日志并通过问题反馈提供诊断信息。

### 安装说明

下载 Windows x64 ZIP 与对应的 `.zip.sha256` 并校验。关闭游戏，备份插件与设置，只替换 `renodx-dlss5.addon64`，避免重复加载，保留许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 `nvngx_dlssnr.dll`；安装包不附带厂商 Runtime、模型、SDK 或 ReShade 加载器。ZIP 内含中英文离线玩家手册。

## English

### Highlights

Region masks let you control how much NR is applied, along with local tone and structure, or gradually reduce NR in the distance to keep the original picture there. Quality and Multi-Pass share the same controls; up to four passes can inherit Pass 1 or use independent settings.

### Features & Improvements

- Choose Uniform control, Full-frame mask or Depth fade. Depth fade modulates red intensity; green tone and blue structure remain independently adjustable.
- Enable Region mask at Quality → Appearance & result → Model styling. Every pass on Multi-Pass also has an entry after model appearance and before result adjustment. The enable switch applies to all passes.
- A fixed depth range scale makes distant thresholds easier to adjust. Far scenery, Sky / far plane, six-decimal input and individual reset buttons are available. Exact depth defaults are `0.999900 / 0.999950`.
- Blend choices are named Replace, Average, Minimum and Maximum. Updated multilingual tooltips explain Character mask interaction, RGB channels and depth endpoints.

### Fixes

- Fixed a retired diagnostic setting and existing processing history preventing NR from continuing on Render, Present or after switching back to Upscaled.
- Improved workset reuse after disabling the region mask and completed related resource lifetime and failure recovery handling.
- Fixed profiles and imports bypassing depth-default migration. The exact old `0.7 / 0.9` defaults migrate; other valid custom ranges are preserved.
- Kept actual and estimated working-resolution rows in fixed positions to prevent menu jumps when switching hook points.
- Added Pass 1's region mask entry, aligned later-pass placement and restored reset-button visibility for small but meaningful depth changes.

### Validation

The user confirmed in-game verification of the latest development candidate before release. Configuration and profile, menu and layout, language, Release/Debug build and 207-scenario UI snapshot checks passed. Earlier targeted WARP, hardware GPU and native NGX validation covers the region mask within the recorded scope of each processing path.

The v0.3.0 tag workflow runs the Windows build, automated tests, PE version and packaging checks. Final assets are checked against source identity, package contents and SHA-256. In-game confirmation covers the user's tested scenes rather than every game and combination.

### Known Limitations

- Region masks require a compatible NR runtime and processing path. Depth is normalized game depth, not metres. Sky / far plane selects depth rather than detecting semantic sky; adjust the range for the game.
- Dark-region and motion-region rules are not available yet. Arbitrary different-sized three/four-pass chains, Vulkan mixed stages/independent scaling and some special native Pre-FG combinations remain unavailable; see the User Guide.
- One earlier report described a hang after enabling the mask. Targeted retesting did not reproduce it, and the cause remains undetermined. If it recurs, retain logs and provide diagnostic information through issue reporting.

### Installation

Download and verify the Windows x64 ZIP and matching `.zip.sha256`. Close the game, back up the add-on/settings, replace only `renodx-dlss5.addon64` and avoid duplicate active copies. Keep the licenses. Supply ReShade with full add-on/API 18 support and a legally obtained compatible `nvngx_dlssnr.dll` separately. Vendor runtimes, models, SDKs and the ReShade loader are not bundled. The ZIP includes a bilingual offline player guide.
