# NR Nexus v0.2.1 — XeFG 单层 Backbuffer / Single-backbuffer default

<!-- Previous: v0.2.0 -->

## 简体中文

### 版本亮点

XeFG + Present 在 AUTO UI Mode、UI Composition 关闭时，默认仅对 Backbuffer 执行 NR，省去原双链中额外的 HUDLess 完整处理链。1 Pass 执行一次模型调用，2 Pass 执行两次，保留所选模型、工作分辨率与 Pass 数，降低这一组合的额外 GPU 开销。

### 新增功能与改进

- **单颜色与双链选择：** 画质页的“处理与兼容性 → Present → FG 高级设置 → XeFG 单颜色处理”默认开启；关闭并重启游戏可恢复原双链。OptiScaler 开启 UI Composition 且 XeFG 实际消费独立 HUDLess 时保留双链，两路场景颜色均经过 NR；其他 UI Mode 沿用既有兼容路由。插件不自动修改 OptiScaler.ini，Render／Upscaled 和原生 DLSS FG 策略保持不变。
- **路径诊断：** 现有 ReShade 日志新增最后一帧实际单层／双链及原因，区分 UI Composition、UI Mode、手动双链和未处理状态；保留区间调用计数。
- **旧配置升级：** 首次升级一次性开启新的默认策略，其他画质参数保持原值；之后手动选择的兼容设置会保存。
- **离线玩家手册：** 安装包附带 `NR-Nexus-Guide.html`，解压后双击即可离线阅读完整中英文 README 和指南，配图内嵌。游戏画面使用已审核的 SDR 静态预览，在线交互对比和外部下载仍需网络。

### 修复内容

- NR 关闭时将 HUDLess 正常交给 XeFG，避免可选屏蔽逻辑吞掉底层资源标签。
- 修正同一游戏帧的两路颜色处理重复观察 Reset，以及缺少新 Present ID 时借用旧引导数据的问题。
- 修正内部 Present 处理覆盖游戏真实 SR／RR 来源证据导致的菜单能力闪烁，保持 Render 与方案可用性判断一致。

### 验证情况

通过 XeFG 资源路由、单／双颜色、NR 开关、1／2 Pass、HDR／SDR、配置、菜单和资源生命周期的定向回归，完成 Release／Debug 及版本资源检查；GPU 合同测试使用模型替身。巫师3 DX12 HDR + XeFG 4x 的本地候选已实际加载并完成 NR 开关、短场景、正常退出和文件恢复：单颜色 1 Pass 的 649 个服务帧对应 649 次 Evaluate，2 Pass 的 797 帧对应 1,594 次，HUDLess 处理均为 0；UI Composition 开启时保留双链。单层结果来自受保护测试中临时关闭 UI Composition 的配置，原文件已恢复；原 OptiScaler UI Composition 开启配置的 1 Pass 为双链、89.82 显示 FPS。单层短测显示 FPS 分别为 103.44／90.68，仅代表本次测试配置与场景。离线手册完成断网浏览器检查，发布附件须通过版本、源码及校验和核对。

本次未完成连续运动、NR 切换与生成帧的动态视觉验收；最终发布附件不另行进行游戏测试。上述本地候选的计数与静态截图不作为这些检查通过的依据。

### 已知限制

Present 仍会处理游戏 HUD、菜单和地图；本版没有新增单次 NR 后的 UI 重组。XeFG 本身及特定游戏的运动、HUD 或高亮瞬闪问题需按实际组合判断。遇到单颜色模式新增的兼容问题可关闭该选项并重启。原生 Pre-FG 双层异尺寸仍为默认关闭的实验路径。

### 安装说明

下载 Windows x64 ZIP 及对应的 `.zip.sha256` 并校验。关闭游戏，备份插件和设置，只替换 `renodx-dlss5.addon64`，避免重复加载，保留许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 `nvngx_dlssnr.dll`；安装包不附带厂商 Runtime、模型或 SDK。

## English

### Highlights

With XeFG + Present, AUTO UI Mode and UI Composition off, NR now defaults to processing only the backbuffer, avoiding the additional full HUD-less chain. 1 Pass makes one model call and 2 Pass makes two, retaining the selected model, working resolution and pass count while reducing the extra GPU cost of this combination.

### Features & Improvements

- **Single-color and dual-chain selection:** “Processing & compatibility → Present → FG advanced settings → XeFG single-color processing” on the Quality page defaults on. Disable it and restart the game to restore the previous dual chain. Enabling UI Composition in OptiScaler retains the dual chain when XeFG actually consumes separate HUD-less input, processing both scene colors with NR. Other UI Modes retain their existing compatibility routes. The add-on does not automatically edit OptiScaler.ini; Render/Upscaled and native DLSS FG policies are unchanged.
- **Route diagnostics:** Existing ReShade logs now identify the last frame’s actual single/dual route and reason, distinguishing UI Composition, UI Mode, manual dual-chain selection and unprocessed frames, while retaining interval call counters.
- **Existing configurations:** The first upgrade enables the new default once, retaining other quality settings. Later manual compatibility choices are saved.
- **Offline player guide:** The ZIP includes `NR-Nexus-Guide.html`. Extract and double-click it to read the complete Chinese and English README and User Guide offline, with embedded images. Game scenes use approved static SDR previews; interactive online comparisons and external downloads still require a connection.

### Fixes

- Forward HUD-less inputs to XeFG normally when NR is off, preventing optional omission from swallowing SDK resource tags.
- Fix repeated observation of game Reset across the two color roles and stale-guide reuse when there is no fresh Present ID.
- Stop internal Present processing from overwriting the game’s actual SR/RR source evidence, keeping Render and profile availability stable.

### Validation

Targeted regressions cover XeFG resource routing, single/dual colors, NR toggles, 1/2 Pass, HDR/SDR, configuration, menus and resource lifetime. Release/Debug builds and version resources passed; GPU contract tests use substitute models. A local candidate was loaded in Witcher 3 DX12 HDR + XeFG 4x and completed NR toggles, a short scene, normal exit and file restoration: 649 single-color service frames made 649 Evaluate calls at 1 Pass; 797 frames made 1,594 calls at 2 Pass, with no HUD-less processing. UI Composition retained the dual chain. These single-color results used a protected test configuration with UI Composition temporarily disabled; the original file was restored. The original OptiScaler configuration with UI Composition enabled used the dual chain at 1 Pass, with 89.82 displayed FPS. Single-color displayed FPS was 103.44/90.68 in these short runs, specific to the test settings and scene. The offline guide passed disconnected-browser checks. Release assets require version, source and checksum verification.

Continuous-motion, NR-toggle and generated-frame visual acceptance was not completed, and the final release attachment will not receive a separate game test. The local candidate counters and static screenshots do not count as passing those checks.

### Known Limitations

Present still processes the game HUD, menus and maps; this version adds no UI reconstruction after a single NR evaluation. XeFG’s own and game-specific motion, HUD or highlight-flicker issues need checking in the actual combination. Disable single-color processing and restart if it introduces a compatibility issue. Native Pre-FG different-sized pairs remain a disabled experiment.

### Installation

Download and verify the Windows x64 ZIP and matching `.zip.sha256`. Close the game, back up the add-on/settings, replace only `renodx-dlss5.addon64` and avoid duplicate active copies. Keep the licenses. Supply ReShade with full add-on/API 18 support and a legally obtained compatible `nvngx_dlssnr.dll` separately; vendor runtimes, models and SDKs are not bundled.
