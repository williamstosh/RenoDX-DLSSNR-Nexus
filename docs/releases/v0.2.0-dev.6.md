## 简体中文

### 版本亮点

开发源码为 **Render → 游戏 DLSS SR/DLAA → Upscaled** 链新增原生 DX11 Bridge 支持，最多四层保留独立模型、外观及结果选择；同时加入默认关闭的 DX12 `Upscaled → Present` 两 Pass 实验。混合链在把 twin 交给游戏 SR 前必须确认 GPU 真正完成。本源码随 v0.2.0-dev.6 预发布包公开。

### 新增功能与改进

- DX11 Render／Upscaled 组使用常驻且按尺寸独立重建的 Bridge 资源。有界完成事件等待防止 Watchdog 救援把未完成数据交给原生 SR；待完成交付会阻止后续 twin 覆盖。
- Render workset 退休改用各组独占描述符堆与 COM 引用，不再以共享源纹理作为整组条件，避免后续 workset 钉住已退休 scratch，同时保留可重放录制与待提交证明。
- 原单阶段路径不变。跨阶段 Present、Vulkan、FG 接管输入及 RR 真正 PreSR 仍停用并说明原因；RR 继续安全回退到 Upscaled。
- 15 语言界面、预设字段、Profile Slot、诊断及阶段 Planner 同样覆盖 DX11；完成等待／失败计数与 NR GPU 样本分开显示。
- DX12 `Upscaled → Present` 实验默认关闭，仅在 INI 设置 `NRExperimentalPresentChain=1` 时接受严格两 Pass 的 SR/DLAA 路径。它要求观测到真实 SR 输出到当前 backbuffer 的同队列完整复制、无重放或竞争写入；证据不足时跳过 B，不重复 A。该实验无游戏／NVIDIA 网络／画质验收。
- Feature 来源切换隔离了输出去重标记；共享 Present History 随真实来源／创建代次变化请求 Reset，并保留跳过时的 pending Reset；诊断记录实际来源计划、最后 NR 调用、Reset 请求／接受及原因。

### 验证情况

最终源码通过受影响自动化：255 个 Planner 配置、8,160 个能力情况、19,056 个模型分配和 156,343 项检查；RTX 5090 D＋WARP 的 AB／BA、合法 2–4 层分组、失败传播、Ring／Watchdog／待交付及退休测试；B1 的 WARP／RTX 5090 D、SDR／scRGB／HDR10、完整复制／队列／重放／竞争写入及失败恢复；Feature Switch 的 WARP／硬件来源切换、Present History 与诊断；DX12 57 配置＋2 边界回归；原生 COM／Detours；UI Quick 27 场景／3,837 项；15 语言品牌；Release／Debug 与 PE。森林之子 DX11 受保护会话使用所有者提供的固定存档、原生 DLSS Quality、4K 输出及 1920×1080 NR 工作尺寸，观测到正确的阶段／Pass 计数与退休；安装、存档和设置完整恢复，未留装候选。

桌面 HDR 截图是 RGB 图像，不是线性 GPU readback；自动化 GPU 测试使用确定性 NR／SR 替身，不证明 NVIDIA 网络身份。

### 已知限制

仅实测一款 DX11 游戏、一个固定存档、两层链及短时稳态窗口。精细运动／残影／闪烁、P95、DLAA、其他 DX11 游戏、长时运行及跨阶段 Present／Vulkan／FG 路径仍未验收。B1 仅有 GPU 替身自动化，尚无实际游戏、NVIDIA 网络或画质验收；依赖特定完整复制／同队列证据，部分游戏会持续被拒绝。B2／P2-C 仍 BLOCKED，B3 仍 NO-GO。混合链增加重复完成等待；帧时间与 GPU 数值不可直接相加。这是开发预发布，不是正式版。

### 安装说明

从 v0.2.0-dev.6 预发布下载 Windows x64 ZIP 并核对 `.zip.sha256`。关闭游戏、备份现有插件与游戏设置后，仅替换 `renodx-dlss5.addon64`，保留包内文档与许可声明。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；A/B 模型要求识别到 310.9.16.0。

## English

### Highlights

The development source adds native DX11 Bridge support for **Render → game DLSS SR/DLAA → Upscaled** chains, with up to four passes keeping independent model, look and result choices, plus a default-off DX12 `Upscaled → Present` two-pass experiment. Each mixed-stage delivery now requires proven GPU completion before its twin is exposed to the game's SR. The v0.2.0-dev.6 pre-release package is published with this source.

### Features & Improvements

- DX11 Render and Upscaled groups use persistent, independently rebuilt bridge resources. A bounded completion-event wait prevents a watchdog rescue from feeding unfinished data into native SR; pending delivery blocks later twin overwrites.
- Render workset retirement now relies on each group's exclusive descriptor heap and COM references instead of the shared source texture, preventing resident scratch from being pinned by later worksets while preserving replay and pending-submission proofs.
- The existing single-stage path is unchanged. Cross-stage Present, Vulkan, FG-owned input and true Ray Reconstruction pre-SR remain disabled with an explanation; Ray Reconstruction continues its safe Upscaled fallback.
- The same 15-language interface, preset fields, Profile Slots, diagnostics and stage planner cover DX11. New completion wait/failure counters are reported separately from NR GPU samples.
- The DX12 `Upscaled → Present` experiment is disabled by default and requires `NRExperimentalPresentChain=1` in the INI. It accepts only a strict two-pass SR/DLAA route with observed same-queue full-copy evidence from the real SR output to the current backbuffer, no replay or competing writer; insufficient proof skips B without repeating A. No game, NVIDIA network or image-quality acceptance is claimed.
- Feature source switching now isolates output deduplication marks; shared Present History requests Reset on real source/creation-generation changes and retains pending Reset when skipped. Diagnostics records the source plan, last NR call, Reset request/acceptance and reason.

### Validation

The final source passed the affected automated suites: 255 planner configurations, 8,160 capability cases, 19,056 model assignments and 156,343 checks; real RTX 5090 D and WARP bridge-motion tests for AB/BA, legal 2–4 pass splits, failure propagation, ring/watchdog/pending-delivery and retirement; B1 WARP/RTX 5090 D SDR/scRGB/HDR10 complete-copy, queue, replay, competing-writer and failure-recovery tests; Feature Switch WARP/hardware source switching, Present History and diagnostics; the DX12 57-configuration plus 2-boundary regression; native COM/Detours; UI Quick 27 scenes/3,837 checks; 15-language branding; Release/Debug and PE metadata. A protected Sons of the Forest DX11 session used a fixed owner-provided save, native DLSS Quality at 4K output with 1920×1080 NR work, and observed correct stage/Pass accounting and retirement; installation, saves and settings were restored with no candidate left installed.

The desktop HDR captures are RGB images, not linear GPU readback. Automated GPU tests use deterministic NR/SR substitutes and do not prove NVIDIA network identity.

### Known Limitations

Only one DX11 game, one fixed save, two-stage chains and short steady-state windows were tested. Fine motion/ghosting/flicker, P95, DLAA, other DX11 games, long sessions and cross-stage Present/Vulkan/FG paths remain unverified. B1 has GPU-substitute automation only, with no actual game, NVIDIA network or image-quality acceptance; it requires specific full-copy and same-queue evidence, so some games will be continuously rejected. B2/P2-C remain BLOCKED and B3 remains NO-GO. The mixed chain adds repeated completion waits; reported frame-time and GPU values are not additive. This is a development pre-release, not a stable release.

### Installation

Download the v0.2.0-dev.6 Windows x64 ZIP from the pre-release and verify its `.zip.sha256`. Close the game, back up the existing add-on and game settings, and replace only `renodx-dlss5.addon64`; keep the included documentation and license notices. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` remain separate requirements; A/B models require a recognized 310.9.16.0 runtime.
