# NR Nexus v0.2.0-dev.6 — DX11 Per-Pass Stages / DX11 逐层阶段

## 简体中文

### 版本亮点

开发源码为 **Render → 游戏 DLSS SR/DLAA → Upscaled** 链新增原生 DX11 Bridge 支持，最多四层保留独立模型、外观及结果选择。混合链在把 twin 交给游戏 SR 前必须确认 GPU 真正完成。此源码版本尚未发布，没有公开的 v0.2.0-dev.6 安装包。

### 新增功能与改进

- DX11 Render／Upscaled 组使用常驻且按尺寸独立重建的 Bridge 资源。有界完成事件等待防止 Watchdog 救援把未完成数据交给原生 SR；待完成交付会阻止后续 twin 覆盖。
- Render workset 退休改用各组独占描述符堆与 COM 引用，不再以共享源纹理作为整组条件，避免后续 workset 钉住已退休 scratch，同时保留可重放录制与待提交证明。
- 原单阶段路径不变。跨阶段 Present、Vulkan、FG 接管输入及 RR 真正 PreSR 仍停用并说明原因；RR 继续安全回退到 Upscaled。
- 15 语言界面、预设字段、Profile Slot、诊断及阶段 Planner 同样覆盖 DX11；完成等待／失败计数与 NR GPU 样本分开显示。

### 验证情况

最终源码通过受影响自动化：255 个 Planner 配置、8,160 个能力情况、19,056 个模型分配和 154,414 项检查；RTX 5090 D＋WARP 的 AB／BA、合法 2–4 层分组、失败传播、Ring／Watchdog／待交付及退休测试；DX12 57 配置＋2 边界回归；原生 COM／Detours；UI Quick 27 场景／3,837 项；15 语言品牌；Release／Debug 与 PE。森林之子 DX11 受保护会话使用所有者提供的固定存档、原生 DLSS Quality、4K 输出及 1920×1080 NR 工作尺寸，观测到正确的阶段／Pass 计数与退休；安装、存档和设置完整恢复，未留装候选。

桌面 HDR 截图是 RGB 图像，不是线性 GPU readback；自动化 GPU 测试使用确定性 NR／SR 替身，不证明 NVIDIA 网络身份。

### 已知限制

仅实测一款 DX11 游戏、一个固定存档、两层链及短时稳态窗口。精细运动／残影／闪烁、P95、DLAA、其他 DX11 游戏、长时运行及跨阶段 Present／Vulkan／FG 路径仍未验收。混合链增加重复完成等待；帧时间与 GPU 数值不可直接相加。当前没有 v0.2.0-dev.6 安装包；最新公开预发布仍为 v0.2.0-dev.5。

### 安装说明

本版本没有公开安装包。需要打包版本时请使用最新公开预发布 v0.2.0-dev.5，它不包含 DX11 逐层阶段。测试此源码须使用固定宿主本地构建，备份设置后仅安装生成的 `renodx-dlss5.addon64`。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；A/B 模型要求识别到 310.9.16.0。

## English

### Highlights

The development source adds native DX11 Bridge support for **Render → game DLSS SR/DLAA → Upscaled** chains, with up to four passes keeping independent model, look and result choices. Each mixed-stage delivery now requires proven GPU completion before its twin is exposed to the game's SR. This source version is unreleased; no v0.2.0-dev.6 package is published.

### Features & Improvements

- DX11 Render and Upscaled groups use persistent, independently rebuilt bridge resources. A bounded completion-event wait prevents a watchdog rescue from feeding unfinished data into native SR; pending delivery blocks later twin overwrites.
- Render workset retirement now relies on each group's exclusive descriptor heap and COM references instead of the shared source texture, preventing resident scratch from being pinned by later worksets while preserving replay and pending-submission proofs.
- The existing single-stage path is unchanged. Cross-stage Present, Vulkan, FG-owned input and true Ray Reconstruction pre-SR remain disabled with an explanation; Ray Reconstruction continues its safe Upscaled fallback.
- The same 15-language interface, preset fields, Profile Slots, diagnostics and stage planner cover DX11. New completion wait/failure counters are reported separately from NR GPU samples.

### Validation

The final source passed the affected automated suites: 255 planner configurations, 8,160 capability cases, 19,056 model assignments and 154,414 checks; real RTX 5090 D and WARP bridge-motion tests for AB/BA, legal 2–4 pass splits, failure propagation, ring/watchdog/pending-delivery and retirement; the DX12 57-configuration plus 2-boundary regression; native COM/Detours; UI Quick 27 scenes/3,837 checks; 15-language branding; Release/Debug and PE metadata. A protected Sons of the Forest DX11 session used a fixed owner-provided save, native DLSS Quality at 4K output with 1920×1080 NR work, and observed correct stage/Pass accounting and retirement; installation, saves and settings were restored with no candidate left installed.

The desktop HDR captures are RGB images, not linear GPU readback. Automated GPU tests use deterministic NR/SR substitutes and do not prove NVIDIA network identity.

### Known Limitations

Only one DX11 game, one fixed save, two-stage chains and short steady-state windows were tested. Fine motion/ghosting/flicker, P95, DLAA, other DX11 games, long sessions and cross-stage Present/Vulkan/FG paths remain unverified. The mixed chain adds repeated completion waits; reported frame-time and GPU values are not additive. No v0.2.0-dev.6 package exists; the latest published pre-release is v0.2.0-dev.5.

### Installation

This version has no published package. For a packaged build, use the latest published pre-release (v0.2.0-dev.5), which does not include DX11 per-pass stages. To test this source, build locally with the pinned host and install only the produced `renodx-dlss5.addon64` after backing up settings. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` remain separate requirements; A/B models require a recognized 310.9.16.0 runtime.
