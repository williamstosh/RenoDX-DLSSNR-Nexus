# NR Nexus v0.2.0-dev.7 — DX11 Stages, Experimental Present and Build Fix / DX11 逐层阶段、实验性 Present 与构建修正

<!-- Previous: v0.2.0-dev.5 -->

## Highlights

This pre-release publishes the feature set prepared for v0.2.0-dev.6: native DX11 Render → game DLSS SR/DLAA → Upscaled stages, the default-off DX12 Upscaled → Present experiment, and the source-switch/Present-history fixes. The v0.2.0-dev.6 tag build was blocked by a test-only D3D11 watchdog-state issue; this release fixes the fixture without changing product behavior. No v0.2.0-dev.7 package existed before this release; the published ZIP accompanies this source.

本预发布发布为 v0.2.0-dev.6 准备的同一功能集：原生 DX11 Render → 游戏 DLSS SR/DLAA → Upscaled 逐层阶段、默认关闭的 DX12 Upscaled → Present 实验，以及来源切换／Present History 修复。v0.2.0-dev.6 Tag 构建仅因测试夹具的 D3D11 Watchdog 状态失败；本版修复夹具，不改变产品行为。发布 ZIP 随本源码公开。

## Features

- Native DX11 Bridge Render/Upscaled groups with independent per-pass models, looks and results, proven completion handoff and corrected retirement of shared scratch.
- Default-off DX12 Upscaled → Present B1 experiment (`NRExperimentalPresentChain=1`) requiring strict two-pass SR/DLAA, same-queue full-copy provenance, replay/competing-write rejection and independent Present history.
- Feature-source output deduplication isolation, shared Present History reset on real source/creation-generation changes, and focused source/Reset diagnostics.

- 原生 DX11 Bridge Render／Upscaled 组，保留逐层模型、外观和结果，要求真实完成证明并修正共享 scratch 退休。
- 默认关闭的 DX12 Upscaled → Present B1 实验（`NRExperimentalPresentChain=1`），限定严格两 Pass SR/DLAA、同队列完整复制来源、重放／竞争写入拒绝及独立 Present History。
- Feature 来源输出去重隔离、真实来源／创建代次变化时重置共享 Present History，以及来源／Reset 诊断。

## Validation

The v0.2.0-dev.6 Release build reached the WARP bridge-motion suite and failed only in its watchdog fixture: after three intentional timeouts the production bridge correctly remained lost for that D3D11 session, while the fixture attempted to reuse it. The fixture now starts a fresh bridge after verifying that behavior. Local Release/Debug builds, the repaired hardware/WARP bridge-motion suite, Planner 156,343 checks, B1 present-chain cases, Feature Switch cases and the DX12 57+2 regression pass; the dev.7 package will be verified after the tag build. The previously recorded Sons of the Forest DX11 stage evidence remains bound to its original candidate.

v0.2.0-dev.6 Release 已进入 WARP bridge-motion 套件，失败仅在 Watchdog 夹具：三次故意超时后生产桥按设计保持本 D3D11 会话 lost，夹具却继续复用。现夹具在验证该行为后重新建立桥。本地 Release／Debug、修复后的硬件／WARP bridge-motion、Planner 156,343 项、B1 present-chain、Feature Switch 及 DX12 57＋2 回归通过；dev.7 附件将在 Tag 构建后核对。此前的森林之子 DX11 阶段证据仍绑定原候选。

## Known Limitations

DX11 mixed-stage evidence covers one game, one fixed save, two stages and short steady-state windows. B1 has GPU-substitute automation only, with no game, NVIDIA network or image-quality acceptance, and strict copy/queue evidence rejects unsupported games. B2/P2-C remain BLOCKED and B3 remains NO-GO. Long sessions, fine motion/ghosting, P95, DLAA, other games and Vulkan remain unverified. This is a development pre-release, not a stable release.

DX11 混合阶段仅覆盖一款游戏、一个固定存档、两层和短时稳态窗口。B1 仅有 GPU 替身自动化，无游戏、NVIDIA 网络或画质验收，严格复制／队列证据会拒绝不支持的游戏。B2／P2-C 仍 BLOCKED，B3 仍 NO-GO。长时、精细运动／残影、P95、DLAA、其他游戏及 Vulkan 仍未验收。这是开发预发布，不是正式版。

## Installation

Download the v0.2.0-dev.7 Windows x64 ZIP from the pre-release and verify its `.zip.sha256`. Close the game, back up the existing add-on and game settings, and replace only `renodx-dlss5.addon64`; keep the included documentation and license notices. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` remain separate requirements; A/B models require a recognized 310.9.16.0 runtime.

从 v0.2.0-dev.7 预发布下载 Windows x64 ZIP 并核对 `.zip.sha256`。关闭游戏、备份现有插件与游戏设置后，仅替换 `renodx-dlss5.addon64`，保留包内文档与许可声明。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；A/B 模型要求识别到 310.9.16.0。
