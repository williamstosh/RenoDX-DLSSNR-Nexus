# NR Nexus v0.2.0-dev.2 — Six NR Profile Slots / 每游戏六个 NR 方案

<!-- Previous: v0.2.0-dev.1 -->

## Highlights

Add six per-game **NR Profile Slots**: three official development candidates and three custom Slots. Switch between saved NR configurations, keep independent official overrides, capture the current game settings into a custom Slot, and undo or restore Slot actions. Slot data is isolated per game and is not written into the shared preset library.

新增每游戏六个 **NR Profile Slot**：三个官方开发候选与三个自定义 Slot。可切换已保存的 NR 配置、分别保留官方方案覆盖值、将当前游戏设置捕获到自定义 Slot，并撤销或恢复 Slot 操作。Slot 数据按游戏隔离，不写入共享预设库。

## Features

- Fixed Slots: **NR Lite** (Render, 1 pass, B, follow input), **NR Balanced** (Upscaled, 1 pass, A, follow input) and **NR Max** (Present, 2 passes, A then B, 100%). These are development starting points, not measured quality rankings. Other managed fields inherit registered defaults.
- Official Slots store personal overrides separately; changing one Slot does not change another. **Restore official defaults** clears only the selected official Slot and can be undone. Custom Slots store snapshots, including saved values for disabled passes.
- Edits are observed after committed configuration changes and saved after about 500 ms. A Slot switch waits for pending writes; failed saves stop the switch. Revision conflicts require reloading before another write.
- Profile identity uses a random local game ID plus an executable-path digest. Copying an INI or moving an installation forks Slot data instead of applying another game's document. Startup restores a selected Slot only when the running NR snapshot still matches the last application.
- The preset manager now supports assigning eligible imported NR fields to a custom Slot and saving or sharing a Slot snapshot. Windows file and folder pickers run on a module-pinned worker; choosing an export destination does not write until the explicit export action.
- The previous temporary Built-in effect / Mine comparison was removed. The six Slots provide persistent per-game alternatives and the four main menu pages, 15 languages and four themes remain.

- 固定 Slot：**NR Lite**（Render／1 层／B／跟随输入）、**NR Balanced**（Upscaled／1 层／A／跟随输入）、**NR Max**（Present／2 层／先 A 后 B／100%）。它们是开发起点，不是实测画质排名；其余管理字段继承注册默认值。
- 官方 Slot 分别保存个人覆盖值，修改一个不影响另一个。**恢复官方默认值**只清除当前官方 Slot，且可撤销；自定义 Slot 保存快照，包括未启用层的保存值。
- 在配置提交后观察编辑，约 500 ms 合并保存。切换 Slot 会等待待写入数据，保存失败不继续切换；revision 冲突需重载后再写。
- 方案身份使用本地随机游戏 ID 与 EXE 路径摘要。复制 INI 或移动安装会 fork Slot 数据，不套用另一个游戏的文档；启动时仅当运行中的 NR 快照仍与上次应用一致才恢复选中关联。
- 预设管理支持将合格的导入 NR 字段分配到自定义 Slot，并保存或分享 Slot 快照。Windows 文件／文件夹选择在持模块引用的 worker 上执行；选择导出路径不会立即写入，仍需明确导出。
- 移除旧的“内置效果／我的”临时比较入口；六个 Slot 提供持久的每游戏替代方案，四页菜单、15 种语言和四套主题保持不变。

## Validation

Release and Debug builds passed, and PE product/file metadata matched `0.2.0-dev.2` with the unchanged `renodx-dlss5.addon64` filename. Focused local checks passed with zero failures: 2,962 configuration checks, 701 preset-store checks plus 72 fresh-process restart checks, 294 profile-store checks plus 6 fresh-process checks, 94 file-dialog checks, 74,840 real-ImGui layout checks, 76,735 production menu checks, 15-language branding checks and 57 lifecycle checks. The dialog tests created real COM objects but replaced Show and Shell execution, so no dialog was displayed and no Explorer window was launched.

These are automated fixture and host-build results. They do not establish actual game loading, Slot switching, GPU execution, file-dialog focus in an overlay, image quality or performance.

Release／Debug 构建通过，PE 产品／文件元数据与 `0.2.0-dev.2` 一致，加载文件名仍为 `renodx-dlss5.addon64`。受影响本地检查零失败：配置 2,962 项、预设存储 701 项及新进程重启 72 项、Slot 存储 294 项及新进程 6 项、文件选择 94 项、真实 ImGui 布局 74,840 项、生产菜单 76,735 项、15 种语言品牌检查及生命周期 57 项。弹窗测试创建真实 COM 对象，但替换 Show 与 Shell 执行，因此没有显示对话框或启动 Explorer。

以上为自动化夹具与宿主构建证据，不代表真实游戏加载、Slot 切换、GPU 执行、叠加层内文件对话框焦点、画质或性能已通过。

## Known Limitations

This milestone did not install or launch a game. Actual Slot application and switching, normal exit and reload persistence, Windows picker focus inside the game overlay, cross-game and cross-API behavior, and GPU/visual/performance results remain unverified. The three official candidates are development data without controlled image-quality comparisons. Real IME composition, candidate windows and resulting text remain a separate unresolved input-host issue; saved UTF-8 data and fixed Slot IDs do not depend on the display name. Slot files, ReShade configuration and GPU execution are not one atomic transaction; force-closing may lose the last pending Slot save.

本轮未安装或启动游戏。实际 Slot 应用与切换、正常退出及重载保存、游戏叠加层内的 Windows 选择器焦点、跨游戏／API 行为以及 GPU／画质／性能均未验收。三个官方方案是开发数据，尚无受控画质对比。真实输入法组词、候选窗与最终文字仍是宿主输入侧的独立未解决问题；已保存 UTF-8 数据与固定 Slot ID 不依赖显示名称。Slot 文件、ReShade 配置与 GPU 执行不是同一原子事务；强退可能丢失最后未完成的 Slot 保存。

## Installation

Download the Windows x64 ZIP from this pre-release and verify its `.zip.sha256`. Close the game, back up the existing add-on and game settings, and replace only `renodx-dlss5.addon64`; keep the included documentation and license notices. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` are separate requirements. A/B models require a recognized 310.9.16.0 runtime.

从本预发布下载 Windows x64 ZIP 并核对 `.zip.sha256`。关闭游戏、备份现有插件与游戏设置后，仅替换 `renodx-dlss5.addon64`，保留包内文档和许可声明。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；A/B 模型要求识别到 310.9.16.0。
