## 简体中文

### 版本亮点

开发源码为第 2–4 层新增独立的 **Render／Upscaled／Present** 阶段，与模型及继承选择分离。原生 DX12 DLSS SR/DLAA 可执行 Render 分组 → 游戏超分 → Upscaled 分组。本源码同时包含 v0.2.0-dev.2 之后的辅助输入与预设界面工作。本源码随 v0.2.0-dev.4 预发布包公开。

### 新增功能与改进

- 第 1 层沿用画质页的介入点；第 2–4 层默认“与上一层相同”，显式阶段必须按 Render → Upscaled → Present 前进。倒退请求会停用整链并保留保存的选择。Ray Reconstruction 将请求 Render 的层放在完成后的 Upscaled 输出上执行。
- DX12 Render 分组提供游戏 SR 输入，Upscaled 分组读取游戏 SR 输出；各阶段分别保留 session、workset、历史、描述符和 GPU 样本。前组部分完成或失败时，后组跳过并标记历史重置。
- 跨阶段 Present、DX11/Vulkan 混合链、未支持的 Streamline fallback 及 FG 接管 NR 输入的路径会停用并说明原因；原单阶段 Present/FG 行为保留。
- 配置、预设字段、六个 Profile Slot 及 15 种语言界面均包含新阶段字段。诊断显示已观测分组、Evaluate、重置、重建、跳过次数、最后尺寸及有结果的 GPU 样本；请求／有效阶段及解析后的模型请求不证明内部网络选择。

### 验证情况

最终源码通过 Release／Debug 及受影响自动化检查。记录覆盖 255 个 Planner 配置、4,080 个能力情况、9,072 个模型分配和 74,686 项检查；3,077 项配置；15 种语言下 81,968 项布局及约 80,000 项生产菜单；57 个 WARP 链配置及 2 个边界；57 项生命周期；108 项游戏工具检查（1 项权限跳过）。巫师3 DX12 HDR 的 AA／AB／BA／BB 实机使用两层和固定存档，七轮均正常菜单退出、detach 并完整恢复。GPU 数值为插件发布样本，不是外部逐帧 Profiler。

以上为开发证据：实机使用最终图像候选；后续源码仅增加原子拒绝日志 latch 与花括号规范化，最终版本重建另行绑定 PE／哈希。

### 已知限制

实机证据只覆盖一款游戏、一个固定存档、两层、短时静止及一次短移动，RR／FG 在本轮受保护配置中临时关闭。长时运行、运动残影／闪烁、更多场景与游戏、动态分辨率、1–4 层热切换及视频级画质仍未验收。跨阶段 Present、DX11/Vulkan 及 FG 接管 NR 输入的路径停用。桌面 HDR 截图是 RGB 桌面图，不是线性 GPU readback。这是开发预发布，不表示正式版。

### 安装说明

从 v0.2.0-dev.4 预发布下载 Windows x64 ZIP 并核对 `.zip.sha256`。关闭游戏、备份现有插件与游戏设置后，仅替换 `renodx-dlss5.addon64`，保留包内文档与许可声明。另需支持完整 Add-on／API 18 的 ReShade 与合法取得的兼容 NVIDIA `nvngx_dlssnr.dll`；A/B 模型要求识别到 310.9.16.0。

## English

### Highlights

The development source adds independent **Render / Upscaled / Present** stages for passes 2–4, separate from model and inheritance choices. On native DX12 DLSS SR/DLAA, the chain can run a Render group, let the game upscale, then run an Upscaled group. This source also includes the assisted-input and preset-interface work that followed v0.2.0-dev.2. The v0.2.0-dev.4 pre-release package is published with this source.

### Features & Improvements

- Pass 1 keeps the Quality page's Hook Point. Passes 2–4 default to **Same as previous**; explicit stages must move in order Render → Upscaled → Present. A backward request disables the chain while preserving the saved choices. Ray Reconstruction runs requested Render passes on its finished output at Upscaled.
- DX12 Render groups provide the game's SR input, and Upscaled groups consume the game's SR output. Separate sessions, worksets, history, descriptors and cost samples are kept per stage. A partial or failed predecessor group skips later groups with a reset.
- Cross-stage Present, mixed DX11/Vulkan chains, unsupported Streamline fallbacks and paths where FG owns the NR input are disabled with an explanation. The existing single-stage Present/FG path remains.
- Configuration, preset fields, six Profile Slots and the 15-language UI include the new stage fields. Diagnostics reports observed group/evaluate/reset/rebuild/skip counters, last sizes and measured GPU samples. Requested/effective stages and resolved model requests do not prove internal network selection.

### Validation

The final source passed Release and Debug builds and the affected automated suites. Recorded coverage includes 255 planner configurations, 4,080 capability cases, 9,072 model assignments and 74,686 checks; 3,077 configuration checks; 81,968 layout and about 80,000 production-menu checks across 15 languages; 57 WARP chain configurations plus 2 boundary cases; 57 lifecycle checks; and 108 game-tool checks with one permission skip. The actual Witcher 3 DX12 HDR AA/AB/BA/BB runs used two stages and a fixed save, with normal menu exit, detach and full restoration in all seven protected sessions. GPU values were published in-plugin samples, not an external per-frame profiler.

These are development results: the game evidence used the final image-tested candidate, while later source changes were limited to an atomic refusal-log latch and bracing. The final version rebuild is separately bound to its PE/hash.

### Known Limitations

The game evidence covers one game, one fixed save, two stages, short still scenes and one short movement, with RR and FG temporarily disabled. Long sessions, motion ghosting/flicker, broader scenes and games, dynamic resolution, 1–4 pass hot switching and video-level image quality remain unverified. Cross-stage Present, DX11/Vulkan and FG-owned NR input paths are disabled. The desktop HDR captures are RGB desktop images, not linear GPU readback. This is a development pre-release; it does not imply a stable release.

### Installation

Download the Windows x64 ZIP from the v0.2.0-dev.4 pre-release and verify its `.zip.sha256`. Close the game, back up the existing add-on and game settings, and replace only `renodx-dlss5.addon64`; keep the included documentation and license notices. ReShade with full add-on support / API 18 and a legally obtained compatible NVIDIA `nvngx_dlssnr.dll` remain separate requirements; A/B models require a recognized 310.9.16.0 runtime.
