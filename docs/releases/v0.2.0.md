## 简体中文

### 版本亮点

0.2.0 将逐层处理位置、独立工作分辨率、六个快速方案和常驻运行监视器带入正式版。画质页保留常用控件，叠层页以执行链和当前 Pass 编辑器组织设置；新增三套主题，可在游玩时更方便地调整配置、观察有效 GPU 数据。

### 新增功能与改进

- **逐层控制：** 最多四层顺序处理，模型、外观、结果与处理位置分别配置。支持的 DX11 Bridge／DX12 路径可组合 Render → 游戏 DLSS SR/DLAA → Upscaled，并保留原生 DLSS FG/MFG 或 XeFG 协同。工作尺寸可继承基础设置、跟随输入或使用固定比例；同阶段双层支持的独立尺寸组合由运行时能力检查决定。
- **官方与自定义方案：** 三个官方槽加三个自定义槽，支持保存、切换、恢复、导入／导出和共享方案库。轻量为 Render／B／75%；均衡为 Present／B／67%，仍是全新配置的默认方案；极致为 Present 两层，P1 为 A／100%／电影感／角色遮罩开启／角色与皮肤 0.80，P2 为 B／100%／默认风格／角色遮罩开启／角色与皮肤 0.50。Present 深度与运动设为可选。
- **保护已有设置：** 官方模板升级保留个人修改，自定义方案独立保存。恢复默认弹窗可分别恢复全部官方方案或清空全部自定义方案，每次打开均默认不勾选。
- **F11 运行监视器：** 独立显示／隐藏并记住本游戏偏好。默认 F8 依次切换精简、详情、精简＋趋势、详情＋趋势；两组快捷键均可修改或解绑，并提示冲突。保留手动位置和尺寸，自动适应内容时重新测量。
- **可靠的性能观察：** 10／30／60 秒趋势按配置代次分段，保留调整前的有效历史。当前 GPU 数字只使用当前有效样本，缺测留空。逐层诊断保留模型创建请求、工作／输出尺寸、GPU 时间，以及手动 GPU A/B 比较。跨阶段参考合计以 ~ 标识，需完整且可比较的阶段组证据。
- **主题与语言：** 新增霓虹紫夜、战术琥珀和极光玻璃，原有四套主题保留，Cyber Neon 仍为默认。新主题名称和描述已本地化；15 种界面语言与原生 Unicode 辅助输入继续可用。

### 修复内容

- 方案可用性根据完整目标配置判断，修正从多 Pass／Present 配置切换时的错误禁用；切换仍保留保存、能力检查、失败回滚与撤销。
- 减少 Home 菜单中重复解析和校验六个方案的 CPU 工作，保留实时环境能力检查。
- 模型请求调整改为短暂屏幕通知，同一事件不会逐帧重复；完整请求和调整原因留在诊断中。
- Fluent Light 与 Midnight OLED 的普通滑块取消突兀的外围矩形描边，保留轨道、圆点及输入反馈。
- 统一屏幕通知与悬浮提示术语，修正新主题翻译和百分比文本的格式校验。

### 验证情况

通过配置／方案迁移、六槽切换与失败回滚、能力矩阵、快捷键、通知、趋势有效性及生产 ImGui 自动化；完成 Release／Debug 构建、语言／品牌检查和 316 个离屏场景，实际审阅五个候选主题、旧主题滑块及常见弹窗。既有定向 GPU 测试使用模型替身，其原有范围保持不变。本次未安装候选或启动游戏。

### 已知限制

兼容性依赖游戏、API、驱动及 NVIDIA Runtime；B 需要已识别的兼容运行时。Present 包含游戏 HUD，且不能绕过 FG、资源或执行证明要求。XeFG 高亮瞬闪仍是已知问题；原生 Pre-FG 双层异尺寸路径保持关闭的实验状态。新版官方配方的画质、游戏内热键／焦点、长期性能及巫师 3 原生 DLSS FG 下的 Home 掉帧修复仍待人工实机确认。

### 安装说明

下载 Windows x64 ZIP 附件及对应 **.zip.sha256**，校验后关闭游戏并备份插件和设置，只替换 **renodx-dlss5.addon64**，避免重复加载。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 **nvngx_dlssnr.dll**；安装包不附带厂商运行时、模型或 SDK。保留已有配置，按包内指南检查状态及具体组合的兼容性。

## English

### Highlights

Version 0.2.0 brings per-pass stages, independent working resolution, six quick profiles and a persistent runtime monitor to stable. Quality keeps common controls visible, while Multi-Pass separates the execution chain from the selected pass editor. Three new themes make configuration and GPU observation more comfortable during play.

### Features & Improvements

- **Per-pass control:** Build a sequential chain of up to four passes with separate model, look, result and processing-stage settings. Supported DX11 Bridge/DX12 paths can combine Render → game DLSS SR/DLAA → Upscaled with native DLSS FG/MFG or XeFG. Working sizes can inherit the base, follow input or use a fixed scale; runtime capabilities determine supported independent-size pairs within one stage.
- **Official and custom profiles:** Three official and three custom slots support saving, switching, restoration, import/export and a shared library. Lite uses Render/B/75%; Balanced uses Present/B/67% and remains the fresh-configuration default. Max uses two Present passes: P1 is A/100%/Cinematic with character masking and skin strength 0.80; P2 is B/100%/Default with character masking and skin strength 0.50. Present depth and motion are optional.
- **Existing-setting protection:** Official template updates retain personal overrides, and custom profiles stay separate. The reset dialog can independently restore all official recipes or clear all custom profiles; both options start unchecked every time.
- **F11 runtime monitor:** Toggle it independently and retain each game's display preference. Default F8 cycles Compact, Details, Compact + Trends and Details + Trends. Both bindings can be changed or cleared and report conflicts. Manual position and size remain available; content is measured again when automatic fitting is active.
- **Performance observation:** Optional 10/30/60-second trends keep valid earlier samples in separate configuration segments. Current GPU numbers require current valid samples, and missing measurements stay empty. Per-pass diagnostics retain creation requests, working/output dimensions, GPU time and manual GPU A/B comparison. Cross-stage reference sums use ~ and require complete, comparable stage-group evidence.
- **Themes and languages:** Add Neon Violet, Tactical Amber and Aurora Glass alongside the original four themes; Cyber Neon stays the default. New theme names and descriptions are localized. The 15 interface languages and native Unicode assisted input remain available.

### Fixes

- Profile availability validates the complete destination, correcting disabled choices when switching from multi-pass/Present configurations. Saving, capability checks, rollback and Undo remain in place.
- Reduce repeated CPU work parsing and validating all six profiles while Home is open, while retaining live environment-capability checks.
- Model request adjustments use a short on-screen notification without per-frame repetition. Diagnostics retain the complete requests and adjustment reasons.
- Remove the outer rectangular outline from ordinary Fluent Light and Midnight OLED sliders, retaining tracks, handles and input feedback.
- Unify on-screen notification and Tooltip terminology; correct new-theme localization and format checks for percentage text.

### Validation

Automated checks cover configuration/profile migration, six-slot switching and rollback, capability matrices, hotkeys, notifications, trend validity and production ImGui. Release/Debug builds, language/branding checks and 316 offscreen scenarios were completed, with actual image inspection of five candidate themes, existing-theme sliders and common dialogs. Earlier targeted GPU tests used substitute models and retain their original scope. No candidate was installed and no game was started for this release preparation.

### Known Limitations

Compatibility depends on the game, API, driver and NVIDIA runtime; B requires an identified compatible runtime. Present includes the game's HUD and retains FG, resource and execution-proof requirements. XeFG highlight flicker remains known, and native Pre-FG two-pass independent sizes remain a disabled experiment. Manual game checks are still needed for the new official recipes, hotkeys/focus, long sessions and the Home-related frame-rate fix with native DLSS FG in The Witcher 3.

### Installation

Download the Windows x64 ZIP asset and matching **.zip.sha256**, verify it, close the game and back up the add-on/settings. Replace only **renodx-dlss5.addon64** and avoid duplicate active copies. Supply ReShade with full add-on/API 18 support and a legally obtained compatible **nvngx_dlssnr.dll** separately; vendor runtimes, models and SDKs are not bundled. Keep existing settings and follow the packaged guide to check status and supported combinations.
