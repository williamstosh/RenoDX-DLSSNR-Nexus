# NR Nexus v0.4.1 — 多层恢复与自适应稳定性修复 / Multi-pass recovery and adaptive stability fixes

<!-- Previous: v0.4.0 -->

## 简体中文

### 版本亮点

修复单层修改介入点后无法重新启用多层的问题，并改进自适应模式的成功帧计数、资源清理和状态诊断。已有工作流程和默认设置保持不变。

### 修复内容

- 停用的层继续保留各自设置。重新启用时，若旧阶段与当前链冲突，会预览必要的阶段调整，经确认后一起应用；取消保留原设置。
- 自适应档位的准备调用不再计入成功处理的源帧，实际模型调用、准备成本和失败状态仍分别记录。
- 修复 FG 服务取消路径重复关闭命令列表的问题。
- 改进准备失败、重试及状态卡切换日志，便于定位持续 Checking 或状态变化。
- 扩展自动回归，覆盖自适应开关、介入点往返、显式重建以及多层恢复与取消操作；同步玩家指南的多层恢复说明。

### 验证情况

功能源码 b5ce5d1 的 Windows CI 已完成 Release 构建、WARP／MOCK 与 CPU 自动测试及打包检查。多层恢复经过真实 ImGui 交互测试，覆盖预览、取消、确认和原有撤销事务。自适应计数修复另有此前真实 GPU／NGX 与巫师3 DX12 有限静态回归证据，范围限于对应候选与路径。

v0.4.1 Tag 工作流会重新执行构建、自动测试、PE 版本和打包检查；最终 ZIP、插件、源码身份及 SHA-256 需在公开前核对。此前实机证据不计作最终发布附件的实机或动态画质验收。

### 已知限制

沿用 v0.4.0 的兼容性范围：自动分辨率主要面向原生 DX12 单阶段路径；首次准备仍可能短暂卡顿并增加显存使用，状态也可能短暂显示部分运行。阶段顺序正确不等于所有跨阶段或 FG 组合均可用；同时存在阶段与 FG 尺寸冲突的组合仍会拒绝。未扩展游戏兼容性或动态画质结论，隔帧编辑复用不包含在本版本中。

### 安装说明

下载 Windows x64 ZIP 与对应 `.zip.sha256` 并校验。关闭游戏，备份插件及设置，只替换 `renodx-dlss5.addon64`，避免重复加载并保留许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 `nvngx_dlssnr.dll`；安装包不附带厂商 Runtime、模型、SDK 或 ReShade 加载器，保留中英文离线 HTML 玩家手册。

## English

### Highlights

Fixes re-enabling multiple passes after editing the hook point with only one pass active, and improves adaptive source-frame accounting, resource cleanup and status diagnostics. Existing workflows and defaults are unchanged.

### Fixes

- Disabled passes retain their individual settings. If saved stages conflict with the current chain when re-enabled, review and confirm the necessary stage changes before applying them together. Cancel keeps the original settings.
- Adaptive level preparation calls no longer count as successfully processed source frames. Actual model calls, preparation cost and failure states remain separately recorded.
- Fixed duplicate command-list closure in the FG service cancellation path.
- Improved setup failure, retry and status-card transition logs to help diagnose persistent Checking or status changes.
- Extended automated regression coverage for adaptive toggles, hook-point round trips, explicit recreation, and multi-pass recovery/cancellation. Updated the player guide's multi-pass recovery instructions.

### Validation

Functional source b5ce5d1 passed Windows CI Release builds, WARP / MOCK and CPU automated tests, and packaging checks. Multi-pass recovery was tested through real ImGui interactions covering preview, Cancel, Confirm and the existing Undo transaction. Earlier hardware GPU / native NGX and limited static Witcher 3 DX12 regression evidence covers the adaptive accounting fix only within the corresponding candidates and paths.

The v0.4.1 tag workflow reruns build, automated tests, PE version and packaging checks. The final ZIP, add-on, source identity and SHA-256 must be verified before publication. Earlier in-game evidence is not acceptance of the final release assets or their dynamic image quality.

### Known Limitations

The v0.4.0 compatibility scope remains: automatic sizing primarily targets native DX12 single-stage paths. Initial preparation can still briefly stall rendering and increase video-memory use, and status can briefly show Partly running. Valid stage order does not make every cross-stage or FG combination supported; combinations with simultaneous stage and FG-size conflicts are still rejected. This release adds no broader game-compatibility or dynamic-image-quality claims. Alternate-frame editing reuse is not included.

### Installation

Download and verify the Windows x64 ZIP and matching `.zip.sha256`. Close the game, back up the add-on/settings, replace only `renodx-dlss5.addon64`, avoid duplicate active copies and keep the licenses. Supply ReShade with full add-on/API 18 support and a legally obtained compatible `nvngx_dlssnr.dll` separately. Vendor runtimes, models, SDKs and the ReShade loader are not bundled. The bilingual offline HTML player guide is retained.
