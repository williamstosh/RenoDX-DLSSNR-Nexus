## 简体中文

### 版本亮点

改进 Present + FG 双 Pass 的分辨率设置：当所选基础分辨率与第二层固定分辨率冲突时，可确认让第二层继承基础分辨率，并一次应用所请求的更改。取消不会修改设置，确认后可撤销或重做。

### 验证情况

配置、能力策略、菜单、布局、品牌与多语言、离线指南（593 项）及定向 UI 快照测试已通过。v0.2.2 发布构建由 Tag 工作流执行构建、测试、版本及打包检查。本次尚未进行游戏内交互、GPU 或视觉实测。

### 已知限制

Present + FG 的双 Pass 仍须使用兼容的工作分辨率；原生 Pre-FG 不支持异尺寸双层。Present 仍会处理游戏 HUD、菜单和地图。

### 安装说明

下载 Windows x64 ZIP 及对应的 `.zip.sha256` 并校验。关闭游戏，备份插件和设置，只替换 `renodx-dlss5.addon64`，避免重复加载，保留许可文件。另行准备支持完整 Add-on／API 18 的 ReShade 和合法取得的兼容 `nvngx_dlssnr.dll`；安装包不附带厂商 Runtime、模型或 SDK。

## English

### Highlights

Present + FG dual-pass resolution editing now offers a confirmation when the selected base resolution conflicts with the second pass’s fixed resolution. Confirming applies the requested change and makes the second pass inherit the base resolution in one operation. Cancel leaves settings unchanged; the confirmed edit supports undo and redo.

### Validation

Configuration, capability policy, menu, layout, branding and language, offline guide (593 checks), and targeted UI snapshot tests passed. The v0.2.2 tag workflow builds and tests the release and checks its version and package. In-game interaction, GPU and visual testing have not been performed for this change.

### Known Limitations

Present + FG dual-pass processing still requires compatible working resolutions; native Pre-FG does not support different-sized pairs. Present still processes the game HUD, menus and maps.

### Installation

Download and verify the Windows x64 ZIP and matching `.zip.sha256`. Close the game, back up the add-on/settings, replace only `renodx-dlss5.addon64` and avoid duplicate active copies. Keep the licenses. Supply ReShade with full add-on/API 18 support and a legally obtained compatible `nvngx_dlssnr.dll` separately; vendor runtimes, models and SDKs are not bundled.
